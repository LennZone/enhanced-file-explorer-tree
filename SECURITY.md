# Security Policy

Enhanced file explorer tree is a pure CSS theme. It contains no scripts and makes no network requests, so the risk of security issues is very low.

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

If you still find something security related, please do not open a public issue. Instead, report it privately through [GitHub's security advisories](https://github.com/LennZone/enhanced-file-explorer-tree/security/advisories/new). You will get an answer as soon as possible.
